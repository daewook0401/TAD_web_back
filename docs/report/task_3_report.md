# task_3 최종 보고: 게시판 카테고리 아이콘 공개 URL 보정

## 배경

게시판 카테고리 API가 이전 `/tad/...` 형식 아이콘 URL을 반환해 이미지 표시가 실패했다.

## 원인 또는 설계 판단

프론트는 카테고리 API의 `iconUrl`을 그대로 이미지 주소로 사용한다. 따라서 운영 DB와 신규 시드 모두 Drive 공개 경로를 사용해야 한다.

## 변경 내용

- 카테고리 아이콘 시드를 `/public/tad/...` 형식으로 변경했다.
- 기존 카테고리 아이콘 DB 데이터 2건을 공개 URL로 보정했다.

## 검증 결과

- 공개 경로 아이콘 2건 확인
- 이전 경로 아이콘 0건 확인

## 영향 범위

- 게시판 카테고리 API와 카테고리 아이콘 표시

## 남은 위험

- Drive 공개 URL base가 변경되면 기존 절대 URL 데이터의 별도 이전이 필요하다.

## 후속 작업

- 프론트 배포 후 브라우저에서 카테고리 아이콘을 확인한다.
