# task_3 수행계획서: 게시판 카테고리 아이콘 공개 URL 보정

## 목표

게시판 카테고리 아이콘 URL을 Drive 공개 경로로 전환해 이미지가 표시되도록 한다.

## 현재 현상 또는 요구사항

- 카테고리 API가 반환하는 운영 DB 아이콘 URL에 `/public`이 없다.
- 프론트는 이 API 값을 그대로 이미지 `src`로 사용한다.

## 확인 방법

- 운영 DB의 `board.tb_post_categories.icon_url`을 확인한다.
- SQL 시드와 프론트 E2E 시드의 URL을 검색한다.
- DB 적용 후 API 데이터 경로를 확인한다.

## 원인 가설

Drive 공개 URL 도입 전의 카테고리 아이콘 주소가 DB와 시드 데이터에 남아 있다.

## 영향 범위

- 게시판 카테고리 API
- 카테고리 아이콘 DB 데이터
- 데이터베이스 시드 SQL

## 검증 방법

1. DB URL 경로 확인
2. 백엔드 전체 테스트 및 bootJar 빌드
3. `main` 자동 배포 확인

## 단계별 작업 개요

1. 시드 SQL과 DB 마이그레이션을 추가한다.
2. 운영 DB 카테고리 아이콘 URL을 보정한다.
3. 테스트·배포를 확인한다.

## 승인

작업지시자의 추가 작업 지시로 승인되었다.
