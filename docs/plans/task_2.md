# task_2 수행계획서: 기존 공개 URL의 `/public` 경로 보정

## 목표

기존 분석·게시판 첨부 URL과 새 파일 URL 생성에서 누락된 `/public` 경로를 보정한다.

## 현재 현상 또는 요구사항

- 운영 DB의 분석 이미지 2건과 게시글 첨부 1건이 `/tad/...` 형식으로 저장되어 있다.
- Drive 공개 파일 주소는 `/public/tad/...` 형식이어야 하므로 이미지가 표시되지 않는다.

## 확인 방법

- DB URL의 경로 부분을 확인한다.
- URL 생성 단위 테스트를 수정한다.
- SQL 적용 후 모든 대상 URL이 `/public/tad/...` 형식인지 확인한다.

## 원인 가설

`minio.public-url`을 사용하는 호환 fallback이 저장소 직접 주소 형식을 유지해 Drive 공개 경로를 누락한다.

## 영향 범위

- 공개 URL 생성 서비스
- 분석 게임의 `screenshot_url`
- 게시글·댓글 첨부의 `file_url`

## 검증 방법

1. 공개 URL 단위 테스트
2. 운영 DB 마이그레이션 적용 및 URL 경로 확인
3. 전체 Gradle 테스트와 bootJar 빌드
4. `main` 자동 배포 성공 확인

## 단계별 작업 개요

1. URL 생성 fallback을 Drive 공개 URL 형식으로 수정한다.
2. 기존 DB URL을 객체 위치 정보로 재구성한다.
3. 테스트·빌드 후 `main`에 푸시한다.

## 승인

작업지시자의 추가 작업 지시로 승인되었다.
